# Arjun Vashisht – Portfolio

Personal portfolio of Arjun Vashisht, Software Development Engineer (React, Python, Django).

Live: https://portfolio-ashy-gamma-46.vercel.app/

A single static page with no build step:

- `index.html` – the site, with inline CSS and JS
- `Arjun_Vashisht_Resume.pdf` – the resume linked from the site
- `profile.jpg` – profile photo
- `llms.txt`, `robots.txt`, `sitemap.xml` – search and AI-crawler metadata
- `vercel.json` – tells Vercel to serve the files as they are, without a build

To preview locally, open `index.html` in a browser or run `python3 -m http.server`.

The previous React version of this site is kept on the `old-react-portfolio` branch.
